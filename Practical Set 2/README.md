
# Practical Set 2

## Subject
Fundamentals of Data Structures and Algorithms (FDSA)

## Practical List

### Practical 2.1 – Linear Search
**Aim:**
Implement the Linear Search algorithm to search for a target license plate in a list of vehicle license plates.

**Concepts Used:**
- Linear Search
- Arrays
- Functions
- Strings
- Time Complexity: O(n)

---

### Practical 2.2 – Binary Search
**Aim:**
Implement both Iterative and Recursive Binary Search algorithms to search for a target book code in a sorted array.

**Concepts Used:**
- Binary Search
- Iterative Approach
- Recursive Approach
- Arrays
- Functions
- Time Complexity: O(log n)

---

## Learning Outcomes

- Understand the working of Linear Search.
- Learn the difference between Linear Search and Binary Search.
- Implement Iterative and Recursive Binary Search.
- Analyze the time complexity of searching algorithms.
- Apply searching techniques to solve real-world problems.
