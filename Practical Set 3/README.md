# Practical Set 3

## Subject
Fundamentals of Data Structures and Algorithms (FDSA)

## Practical List

### Practical 3.1 – Sorting Algorithms
**Aim:**
Implement Bubble Sort, Selection Sort, and Insertion Sort to sort an array of integers.

**Concepts Used:**
- Bubble Sort
- Selection Sort
- Insertion Sort
- Arrays
- Functions
- Time Complexity Analysis

---

### Practical 3.2 – Dutch National Flag Algorithm
**Aim:**
Implement the Dutch National Flag Algorithm to sort an array containing only 0s, 1s, and 2s.

**Concepts Used:**
- Dutch National Flag Algorithm
- Three Pointer Technique (Low, Mid, High)
- Arrays
- Sorting
- Time Complexity: O(n)
- Space Complexity: O(1)

---

## Learning Outcomes

- Understand the working of Bubble Sort, Selection Sort, and Insertion Sort.
- Compare different sorting algorithms based on their performance.
- Learn the Dutch National Flag Algorithm for efficient sorting.
- Analyze the time and space complexity of sorting techniques.
- Develop problem-solving and algorithm implementation skills using C++.
